\section{What is this}
This is the sample document for \texttt{latex-convert}.
Drag it onto the app icon (or run \texttt{convert.sh both examples/demo.tex})
and you will get a \texttt{.pdf} and a \texttt{.docx} next to it.

\section{Math}
Inline math $E = mc^2$, and a display equation:
\begin{equation}
  \int_{-\infty}^{\infty} e^{-x^2}\,\mathrm{d}x = \sqrt{\pi}.
\end{equation}

\section{Lists}
\begin{itemize}
  \item Word: produced by \texttt{pandoc}.
  \item PDF: compiled by a local LaTeX engine (twice, so cross-references settle).
\end{itemize}
